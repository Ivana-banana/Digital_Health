## `design_clf_min.ipynb` — минимальный артефакт (модель A, P0)

LR-голова на замороженных эмбеддингах для классификатора **дизайна исследования**
(«ценность там, где Publication Type молчит», plan §7). Обучается минуты на CPU.

**Где запускать:** Yandex Cloud → **DataSphere** → community → project → загрузить ноутбук → Run All.
**Чекпойнт:** сохраняется в Object Storage (бакет проекта). **Метрика:** per-class F1
на human-checked gold (50–100), цель 0.7–0.8.

Апгрейд (P2): дообучение `PubMedBERT` вместо LR-головы.
