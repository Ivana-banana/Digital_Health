# Eval-харнесс (plan §10)

Главный инструмент измерения качества. Два режима:

- **frozen** — кэш/canned-корпус, источник истины для CI и цифр на питче (детерминизм).
- **live** — ручной smoke, не гейтит.

## Cochrane-репро benchmark

Берём опубликованный Cochrane-мета-анализ → его список включённых исследований +
пулед-оценка = **ground truth**. Метрика: совпадает ли наш forest plot / пул с Cochrane.
Это и проверка корректности, и killer-аргумент на питче.

`gold/` — gold-кейсы. P0: заведён каркас одного кейса (`cochrane_case_01.json`);
числовой ground truth заполняется из выбранного опубликованного обзора в P1/P2.
Hallucinated-reference rate = 0 — хард-гейт (plan §10).
